# The address words in the assembled data, for check_relocations.py, which
# the 64-bit link runs (Makefile.native). One rule per line:
#
#     object  symbol  class
#
# object is an object's path under the build directory, symbol a label in
# it (both may use * and ?; {stem} in a symbol is the object's file name
# without .o). The first rule that matches a symbol gives its class. Every
# address word belongs to the symbol at or before it; every such symbol
# must match a rule, and every rule must match a symbol.
#
#   pointer   C reads these words as 8-byte pointers at 64 bits (struct or
#             array members): each must be 8 bytes and 8-byte aligned.
#   table     a pointer array and nothing else: as "pointer", and its words
#             fill it up to the next symbol, so bytecode that follows it
#             without a label of its own cannot be widened with it.
#   packed    8-byte pointers in a packed struct (ObjectEventTemplate is
#             packed, aligned(4)); any alignment.
#   operands  battle script bytecode: src/battle_script_commands.c reads
#             each command's operands through CMD_ARGS, a packed struct over
#             the bytes, so every address in it is an 8-byte pointer at 64
#             bits, at any alignment (asm/macros/battle_script.inc;
#             check_battle_script_operands.py checks the macros).
#   tone      an array of struct ToneData (24 bytes at 64 bits): the wav
#             pointer is 8 bytes at offset 8; voice_keysplit's key-split
#             table address stays 4 bytes in attack..release (offset 16).
#   bytecode  event, animation, contest AI, field effect, mystery gift and
#             song bytecode, read a byte at a time (T1/T2_READ_*,
#             ScriptReadWord, the m4a sequencer) with explicit 4-byte steps:
#             every address stays 4 bytes.
#   label     a symbol that owns no data: keysplit_* labels sit before
#             their table (sound/keysplit_tables.inc), inside the
#             voicegroup before it.
#
# Derived from a measurement made before the 64-bit work, which first counted the battle scripts as 4-byte
# bytecode. An upstream table or object that is not here fails the 64-bit
# build until it is classified.
#
# Counts at expansion 1.17.1 (data/*.o and the 530 songs; TEST=0 and 1
# alike): 61,154 address words, 19,208 of them 8 bytes and 41,946 4 bytes
# (41,522 bytecode and the 424 key-split words). That measurement's 17,033
# and 44,121 became 17,034 and 44,120 when gScriptCmdTableEnd's word was
# widened, then 19,208 and 41,946 with the battle scripts' 2,174 operands.
